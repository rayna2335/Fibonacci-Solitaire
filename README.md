# Solitaire
Fibonacci Solitaire is a card game implemented using a standard deck of 52 cards. Players reveal cards one by one, summing their values. Whenever the sum of the revealed cards forms a Fibonacci number, the pile is discarded. The game continues until either the deck is empty or a Fibonacci pile is formed with the last card, determining a win or loss.

## Features
* Standard 52 card deck
* Players reveal cards, summing their values; if the sum is a Fibonacci number, the pile is discarded. 
* The game continues until the deck is empty or a Fibonacci pile is formed with the last card, determining a win or loss.
* Classes for Deck and Card manage the game's logic.

## Tech used
* **language**: C++
