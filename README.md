# Solitaire
Fibonacci Solitaire is a card game using a standard deck. Players reveal cards, summing their values; if the sum is a Fibonacci number, the pile is discarded. 
The game continues until the deck is empty or a Fibonacci pile is formed with the last card, determining a win or loss. Classes for Deck and Card manage the game's logic.


## Features
* Standard 52 card deck

* **language**: Python
